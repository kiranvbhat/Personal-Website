{%- comment -%} The sidebar, like the GeoCities one (geo/sidebar.html): the site name, then the menu, contact, social and settings sections. On wide screens it sits beside the page and stays in view while scrolling. On small screens, like the GeoCities mobile bar, the sections are hidden behind a row of buttons, one per section, with the name's initials at its start (linking home): each button opens its section under the row (and closes the others); pressing it again, Escape or a tap outside closes it. (The script marks the page so the CSS only hides the sections when the buttons work; without JavaScript they just show.) Menu: _data/nav.yml (the same list as the GeoCities sidebar), each link going to the page's Minimal version in minimal/. Each link can have an emoji or logo before it (sidebar-icon.html): the menu's from `emoji` in nav.yml, the social networks' from `logo` in profile.yml. Contact: email and the resume (the PDF, through /resume, in a new tab). Social: profile.yml. Settings: theme (appearance-select.html) and color (color-setting.html). {%- endcomment -%} {%- assign current_url = page.url | remove: ".html" -%} {%- assign profile = site.data.profile -%}
