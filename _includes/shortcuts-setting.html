{%- comment -%} Keyboard shortcuts setting, for both appearances' settings: On and Off buttons, with the current one pressed in (a .toggle, like color-setting.html). Off turns off every shortcut (shortcut-keys.html's letters and arrow-keys.html's arrows) and hides the key hints next to the settings. Some visitors need that: voice control can set off a one-letter shortcut by accident (e.g. saying a word that starts with Z). The choice is saved in the browser, shared by both appearances, and put on as data-shortcuts="off" (shortcuts-init.html applies it on each page load). {%- endcomment -%}
