{%- comment -%} Letter keys for the settings, on every page of both appearances (the layouts include this): Z switch theme (GeoCities / Minimal), like clicking the other option in appearance-select.html X switch colors (dark / light), like clicking the other option in color-setting.html C open or close the cursor menu (GeoCities only; see geo/cursor-setting.html) Ignored while typing (e.g. in the guestbook), with Ctrl, Alt, Cmd or Shift held (so shortcuts like Cmd+C still copy), when the key is held down, and when shortcuts are turned off in settings (shortcuts-setting.html). The settings show each key next to its setting, e.g. "theme (Z)" (`.key-hint`). {%- endcomment -%}
