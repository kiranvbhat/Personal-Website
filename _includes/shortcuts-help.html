{%- comment -%} The keyboard shortcuts window, opened by the "?" button beside the shortcuts setting's On/Off switch (in both appearances' settings, with id="shortcuts-help-open"). Lists what each key does (see shortcut-keys.html and arrow-keys.html). It's added at the end of the page (by the layouts) rather than in the sidebar, so it still opens when the sidebar's section is hidden, like on small screens. Styled by each appearance: an old Windows window (geocities.css) or a plain card (modern.css). Both appearances list the same keys; the ones that only work in one are marked "(Modern only)" or "(GeoCities only)". Params: appearance "geocities" or "modern" (for the close button's look) {%- endcomment -%}
