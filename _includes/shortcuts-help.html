{%- comment -%} The keyboard shortcuts window, opened by the "?" button beside the shortcuts setting's On/Off switch (in both appearances' settings, with id="shortcuts-help-open"). Lists what each key does (see shortcut-keys.html and arrow-keys.html). It's added at the end of the page (by the layouts) rather than in the sidebar, so it still opens when the sidebar's section is hidden, like on small screens. Styled by each appearance: an old Windows window (geocities.css) or a plain card (minimal.css). Params: appearance "geocities" or "minimal" (they have a few different keys) {%- endcomment -%}
